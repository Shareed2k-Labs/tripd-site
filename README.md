# tripd-site

Static site for tripd, served by GitHub Pages at https://tripd.shareed2k.win.

- `index.html`: landing page.
- `privacy.html`: privacy policy (the URL given to Google Play). Contact address: shareed2k@gmail.com.
- `CNAME`: custom domain.

Setup steps are in the tripd repo, `docs/play/site-setup.md`.
